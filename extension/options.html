Silenzio settings

Scope

Decide which sites Silenzio runs on. Hostname suffix match — adding youtube.com covers all subdomains.

    Working hours

    When enabled, Silenzio is active during these hours and inactive outside them.

    Per-URL rules

    Override modes for specific URLs. Pattern is hostname/path; end the path with * for prefix match. Hostname is suffix-matched (so linkedin.com covers www.linkedin.com). First match wins; otherwise the modes above apply.

      Long-press reveal

      Hold a blurred image or video for ~400ms to peek at it; release to re-apply the filter. Long-press also suppresses the link click, so peeking a blurred linked image won't navigate.

      Global pause

      Pause Silenzio everywhere for a fixed window.
